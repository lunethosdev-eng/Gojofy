# Gojofy 🎵

App de música con estilo anime kawaii + vibes.

## Cómo obtener el APK

1. Ve a la pestaña **Actions**
2. Espera a que termine el workflow **Build Android APK**
3. Descarga el artifact `gojofy-apk`
4. Instala el `.apk`
